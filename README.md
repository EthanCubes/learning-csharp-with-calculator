## Features
- Numerical calculations similar to some basic physical calculators
- Precise decimal calculation that doesn't have errors associated with float values.
- Graphical interface that look somewhat nice

## How to build from source
- Clone the GitHub repo
- Install [dotnet](https://dotnet.microsoft.com/en-us/download)
- In the root of the Git repo, open a terminal.
- In the terminal, run `dotnet new console`
- Run `dotnet build` to build to program
- Run `dotnet run` to run the program
